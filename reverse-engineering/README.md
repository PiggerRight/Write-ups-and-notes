# Reverse Engineering

A personal knowledge base for Reverse Engineering, documenting tools, fundamental concepts, commands, and techniques learned through CTF challenges and practice.

## 📂 Contents

- **Tools** — Commands, usage, and notes for reverse engineering tools.
- **Concepts** — Fundamental concepts such as assembly, ELF, memory layout, and static/dynamic analysis.
- **CTF Write-ups** — Notes and solutions from reverse engineering challenges.
